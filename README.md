# Статистика — продажи и остатки

Локальная программа для Windows x64. Она загружает товарную ведомость, предлагает товарные группы и сохраняет таблицу в Excel. Исходные файлы не меняются и не отправляются по сети.

## Скачать и запустить

1. Откройте [GitHub Releases](https://github.com/slchumak75-sketch/statistika/releases/latest).
2. В разделе **Assets** скачайте **Statistika.exe** и запустите его. Python и Excel для работы с программой не требуются. Сборка не подписана цифровой подписью.

Релиз v1.0.0 не включает новые возможности из этого описания. Актуальная проверенная сборка ветки доступна как артефакт `Statistika-Windows-x64` в [Actions](https://github.com/slchumak75-sketch/statistika/actions).

В программу уже встроены все **74 пункта** файла `4-торг инст..pdf` — указаний Белстата от 19.06.2026 № 33. Для назначения доступны **№35–43, 45, 46, 53, 57, 63 и №100 — «Чулочно-носочные изделия»**. Номера пунктов не совпадают с номерами строк формы: например, пункт 35 относится к строке 22, но в таблице отображается №35.

## Открыть `Ведомость 16.11.2026 (ОК).xlsx`

1. Нажмите **Открыть ведомость…** и выберите файл. Профиль **«Остатки ТМЦ на складах»** открывает сразу готовый отчёт с группами, без исходной таблицы и кнопки конвертации. Если в книге несколько листов, выберите нужный.
2. В шапке отчёта выберите **Период с … по …**. Сначала показаны все 37 месяцев ведомости; после выбора границ цифры и сводка пересчитываются без повторного открытия файла. Склад, фильтр и ручные группы не меняются. **Количество → Расход за весь период** использует другой источник, без выбора месяцев. Если месячные значения или расход не означают продаж, выберите **Не заполнять**.
3. Выберите **Склад** или оставьте «Все склады». Нажмите **№ пункта и описание ▾** в шапке таблицы и выберите конкретную группу, строки без группы или все строки. Чтобы **изменить группу товара**, нажмите на ячейку первого столбца или `Enter` на выбранной строке; `Esc` закрывает список без изменения.
4. Во вкладке **Сводка по группам** показаны итоги выбранного склада. Количества складываются без пересчёта единиц: например, 2 шт. + 3 банки дают итог 5 ед. Строка «Без группы» тоже учитывается. Звёздочка означает частичный итог, когда в некоторых строках нет значения.
5. **Сохранить Excel…** экспортирует шесть детальных столбцов и отдельную сводку за текущий период. Экспортируются все строки **выбранного склада**, в том числе без группы. Фильтр группы в шапке программы действует только на просмотр; в сохранённой книге работает обычный фильтр Excel.

Для **№53 — «Строительные материалы»** используется один список правил. В нём распознаются американки, трубные фитинги, крепёж, малярный инструмент и другие уточнённые товарные семейства, в том числе защитные автоматы и УЗО. [Примеры проверки по ведомости](docs/recognition.md#как-проверяли-пункт-53).

### Какие числа берутся из ведомости ТМЦ

| Результат | Источник |
|---|---|
| № пункта и описание | Встроенный справочник. Для нераспознанной или неоднозначной позиции — пусто |
| Наименование товара | `E` — «Номенклатура» |
| Продано за период, шт.* | Сумма количеств выбранных месяцев из `Q:BA`. Проверьте, что месячные значения означают продажи. Другие варианты: оставить пустым или взять `I` — «Расход» за весь период. Пропуск в выбранном месяце не ноль |
| Продано за период, руб. (столбец D) | Количество из столбца C × `N` — розничная цена из ведомости. Например, 13 × 8 = 104 руб. При нулевом количестве — 0; без количества или без одной числовой цены для ненулевого количества — пусто |
| Остаток на конец, шт.* | `J` — снимок на 15.11.2026. Если выбранный период заканчивается раньше ноября 2026, остаётся пустым: истории остатков нет |
| Остаток на конец, руб. | `J × N` — конечное количество × розничная цена (п. 16 указаний). Нулевой остаток даёт ноль. Если для ненулевого остатка нет одной числовой цены, значение не рассчитывается |

В этой ведомости импортировано **33 224 товарные строки**: 19 948 в «Склад Мир» и 13 276 в «Склад Кореличи». Одноимённые строки не объединяются. Ноябрь 2026 неполный (по 15.11.2026), что отражено в периоде отчёта. В детальной таблице денежные колонки подписаны в рублях, а «шт.*» означает количество в единицах ведомости. Поштучные позиции показаны в штуках, у остальных сохраняется исходная единица `F` (например, банка, упаковка или метр). В сводке все известные количества складываются как числа, в том числе когда единица не указана.

В примечаниях к заголовкам Excel указаны источники данных. Столбец D для ведомости ТМЦ — расчёт по розничной цене из этого файла, а не фактическая выручка. Если в другой ведомости сумма продаж дана отдельным столбцом, программа берёт указанную в ней сумму.

## Другие ведомости и справочники

- При наличии пяти однозначно распознанных полей (товар, количество продаж, сумма продаж, количество и сумма конечного остатка) также открывается сразу готовый отчёт. Форматы: `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.tsv`. Только если заголовки не определены, программа предлагает указать столбцы вручную, без предпросмотра исходной таблицы. Для файла без заголовка укажите `0` и `0`. Формулы Excel предварительно пересчитайте и сохраните: читаются сохранённые значения.
- CSV поддерживает разделители `;`, запятую и табуляцию, кодировки UTF-8, Windows-1251 и UTF-16 с BOM. Десятичная запятая и точка поддерживаются. Пустое значение и прочерк остаются пустыми, числовой `0` сохраняется. Итоги и повторные заголовки пропускаются. Детальные строки не суммируются.
- Автогруппировка использует **только название товара**. Столбец «Группа номенклатуры» не нужен и не влияет на результат. Совпадение разных групп или отсутствие совпадения оставляет ячейку пустой.
- В **Справочник групп… → Правила распознавания** найдите нужный текст через **Поиск по фразам**. Можно искать по всем группам или выбрать одну в верхнем списке. Под списком показан полный текст пункта. Чтобы добавить фразу в эту группу, введите её в **Включить фразу** и нажмите **Включить**. Галочка слева включает фразу в распознавание. Щелчок в столбце **Исключение** ставит или снимает отметку запрета назначения этой группы при совпадении. Там, где исключения нет, ячейка пустая. **Удалить** убирает запись. Нажмите **Сохранить справочник**, чтобы применить правки. Автоназначения пересчитаются, ручные останутся.
- На вкладке **Пункты PDF** можно просмотреть, загрузить или поправить текст указаний. Для загрузки в PDF нужен текстовый слой. Кнопка **Встроенный справочник** восстанавливает исходные описания. Локальные настройки хранятся в `%LOCALAPPDATA%\Statistika\catalog.json`. См. [примеры распознавания и проверку №53](docs/recognition.md).

## Сборка и развитие

GitHub Actions запускается на каждый `push`: тесты → сборка Windows x64 → проверка запуска EXE → артефакт `Statistika-Windows-x64`. Публикация в Releases включается явным релизным коммитом; см. [AGENTS.md](AGENTS.md).

Локальная разработка на Windows: Python 3.12 с Tcl/Tk. В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m statistika
```

Сборка `dist\Statistika.exe` на Windows:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --name Statistika --paths . --add-data "statistika/data/catalog.json:statistika/data" statistika/__main__.py
```
