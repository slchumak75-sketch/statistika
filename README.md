# Статистика — продажи и остатки

Локальная программа для Windows x64. Она загружает товарную ведомость, предлагает товарные группы и сохраняет таблицу в Excel. Исходные файлы не меняются и не отправляются по сети.

## Скачать и запустить

1. Откройте [GitHub Releases](https://github.com/slchumak75-sketch/statistika/releases/latest).
2. В разделе **Assets** скачайте **Statistika.exe** и запустите его. Python и Excel для работы с программой не требуются. Сборка не подписана цифровой подписью.

В программу уже встроены все **74 пункта** файла `4-торг инст..pdf` — указаний Белстата от 19.06.2026 № 33. Для назначения доступны **№35–43, 45, 46, 53, 57, 63 и №100 — «Чулочно-носочные изделия»**. Номера пунктов не совпадают с номерами строк формы: например, пункт 35 относится к строке 22, но в таблице отображается №35.

## Открыть `Ведомость 16.11.2026 (ОК).xlsx`

1. Нажмите **Открыть ведомость…** и выберите файл. Программа распознает профиль **«Остатки ТМЦ на складах»** на листе `Лист_1`. Проверьте период, показанный в окне импорта (`01.11.2023–15.11.2026` в исходном файле).
2. В поле **Источник количества продаж** оставьте «Не заполнять» либо осознанно выберите помесячные количества или «Расход». Выбирайте их только если настройки выгрузки подтверждают, что это именно продажи за требуемый период.
3. Нажмите **Построить таблицу**. Выберите **Только с группой**, чтобы увидеть распознанные позиции, или **Только без группы**, чтобы проверить остальные. Щёлкните первый столбец (или нажмите `Enter` на выбранной строке), чтобы назначить другую группу или очистить ячейку. В диалоге выбора видно полное описание из PDF.
4. Нажмите **Сохранить Excel…**. В файле будут все строки, в том числе нераспределённые и скрытые фильтром. Сохраните результат перед закрытием: ручные назначения относятся к открытой ведомости.

### Какие числа берутся из ведомости ТМЦ

| Результат | Источник |
|---|---|
| № пункта и описание | Встроенный справочник. Для нераспознанной или неоднозначной позиции — пусто |
| Наименование товара | `E` — «Номенклатура» |
| Количество, проданное за период | По умолчанию пусто. Если подтверждён источник: сумма количеств из `Q:BA` либо `I` — «Расход». Это разные показатели; не заменяют друг друга автоматически |
| Сумма продаж за период | **Пусто**: в ведомости нет фактической выручки. Нужна выгрузка продаж с суммами по фактическим ценам |
| Количество в остатке на конец периода | `J` — «Конечный остаток» |
| Сумма остатка на конец периода | `J × N` — конечное количество × розничная цена (п. 16 указаний). Нулевой остаток даёт ноль. Если для ненулевого остатка нет одной числовой цены, значение не рассчитывается |

В этой ведомости импортировано **33 224 товарные строки** без объединения складов или одинаковых названий. При экспорте способ расчёта указан в примечаниях к заголовкам Excel. Из текущей розничной цены нельзя восстановить историческую выручку с учётом цен и скидок, поэтому приложение её не вычисляет.

## Другие ведомости и справочники

- При наличии пяти прямых исходных полей (товар, количество продаж, сумма продаж, количество и сумма конечного остатка) используется обычное сопоставление. Форматы: `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.tsv`. Проверьте лист, заголовок и размеры периода. Неоднозначные поля выбираются вручную. Для файла без заголовка укажите `0` и `0`. Формулы Excel предварительно пересчитайте и сохраните: читаются сохранённые значения.
- CSV поддерживает разделители `;`, запятую и табуляцию, кодировки UTF-8, Windows-1251 и UTF-16 с BOM. Десятичная запятая и точка поддерживаются. Пустое значение и прочерк остаются пустыми, числовой `0` сохраняется. Итоги и повторные заголовки пропускаются. Детальные строки не суммируются.
- Автогруппировка использует правила по названиям и, для отдельных строительных товаров, дополнительный контекст поля «Группа номенклатуры». Если нет уверенного совпадения или совпало несколько групп, первый столбец пуст. Проверяйте неоднозначные позиции по упаковке или коду товара. Дополнительные фразы можно ввести через **Справочник групп… → Правила распознавания**. При изменении справочника ручные назначения сохраняются.
- **Справочник групп…** показывает полный текст всех пунктов. Другую версию можно загрузить из PDF с текстовым слоем и проверить перед сохранением. Для скана нужен OCR или ручной ввод. Кнопка **Встроенный справочник** восстанавливает исходный текст 4-торг. Локальная копия хранится в `%LOCALAPPDATA%\Statistika\catalog.json`.

## Сборка и развитие

GitHub Actions запускается на каждый `push`: тесты → сборка Windows x64 → проверка запуска EXE → артефакт `Statistika-Windows-x64`. Публикация в Releases включается явным релизным коммитом; см. [AGENTS.md](AGENTS.md).

Локальная разработка на Windows: Python 3.12 с Tcl/Tk. В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m statistika
```

Сборка `dist\Statistika.exe` на Windows:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --name Statistika --paths . --add-data "statistika/data/catalog.json:statistika/data" statistika/__main__.py
```
