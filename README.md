# Статистика — продажи и остатки

Локальная программа для Windows x64. Она загружает товарную ведомость, предлагает товарные группы и сохраняет таблицу в Excel. Исходные файлы не меняются и не отправляются по сети.

## Скачать и запустить

1. Откройте [GitHub Releases](https://github.com/slchumak75-sketch/statistika/releases/latest).
2. В разделе **Assets** скачайте **Statistika.exe** и запустите его. Python и Excel для работы с программой не требуются. Сборка не подписана цифровой подписью.

Релиз v1.0.0 не включает новые возможности из этого описания. Актуальная проверенная сборка ветки доступна как артефакт `Statistika-Windows-x64` в [Actions](https://github.com/slchumak75-sketch/statistika/actions).

В программу уже встроены все **74 пункта** файла `4-торг инст..pdf` — указаний Белстата от 19.06.2026 № 33. Для назначения доступны **№35–43, 45, 46, 53, 57, 63 и №100 — «Чулочно-носочные изделия»**. Номера пунктов не совпадают с номерами строк формы: например, пункт 35 относится к строке 22, но в таблице отображается №35.

## Открыть `Ведомость 16.11.2026 (ОК).xlsx`

1. Нажмите **Открыть ведомость…** и выберите файл. Профиль **«Остатки ТМЦ на складах»** открывает сразу готовый отчёт с группами, без исходной таблицы и кнопки конвертации. Если в книге несколько листов, выберите нужный.
2. В шапке отчёта выберите **Период с … по …**. Сначала показаны все 37 месяцев ведомости; после выбора границ цифры и сводка пересчитываются без повторного открытия файла. Склад, фильтр и ручные группы не меняются. **Количество → Расход за весь период** использует другой источник, без выбора месяцев. Если месячные значения или расход не означают продаж, выберите **Не заполнять**.
3. Выберите **Склад** или оставьте «Все склады». Щелчок по ячейке **№ пункта и описание** либо `Enter` открывает список у выбранной строки; можно назначить группу или выбрать «Без группы». `Esc` закрывает список без изменения.
4. Во вкладке **Сводка по группам** показаны итоги выбранного склада. Раскройте группу, чтобы увидеть количества по разным единицам. Строка «Без группы» тоже учитывается. Звёздочка означает частичный итог.
5. **Сохранить Excel…** экспортирует шесть детальных столбцов и отдельную сводку за текущий период. Экспортируются все строки **выбранного склада**, в том числе без группы. Фильтры «Только с группой» / «Только без группы» действуют лишь на просмотр.

**Электромонтаж в №53 (внутренний отчёт)** — отдельный переключатель. С ним распознанные автоматы, УЗО, установочные выключатели, кабели и другие опознанные электромонтажные позиции добавляются во внутреннюю стройгруппу. В обычном режиме они не включаются в строку 51 формы 4-торг. Во внутреннем режиме это отличие явно отмечено и на экране, и в Excel. Американки, трубы и прочие подтверждённые стройматериалы распознаются в обоих режимах. [Проверка по всей ведомости и источники](docs/recognition.md#как-проверяли-пункт-53).

### Какие числа берутся из ведомости ТМЦ

| Результат | Источник |
|---|---|
| № пункта и описание | Встроенный справочник. Для нераспознанной или неоднозначной позиции — пусто |
| Наименование товара | `E` — «Номенклатура» |
| Количество, проданное за период | Сумма количеств выбранных месяцев из `Q:BA`. Проверьте, что месячные значения означают продажи. Другие варианты: оставить пустым или взять `I` — «Расход» за весь период. Пропуск в выбранном месяце не ноль, выручка не вычисляется |
| Сумма продаж за период | **Пусто**: в ведомости нет фактической выручки. Нужна выгрузка продаж с суммами по фактическим ценам |
| Количество в остатке на конец периода | `J` — снимок на 15.11.2026. Если выбранный период заканчивается раньше ноября 2026, остаётся пустым: истории остатков нет |
| Сумма остатка на конец периода | `J × N` — конечное количество × розничная цена (п. 16 указаний). Нулевой остаток даёт ноль. Если для ненулевого остатка нет одной числовой цены, значение не рассчитывается |

В этой ведомости импортировано **33 224 товарные строки**: 19 948 в «Склад Мир» и 13 276 в «Склад Кореличи». Одноимённые строки не объединяются. Ноябрь 2026 неполный (по 15.11.2026), что отражено в периоде отчёта. Денежные колонки подписаны в рублях. Количества штучных товаров показаны в штуках; для других товаров сохраняется исходная единица `F`. В сводке количества в метрах, упаковках, штуках и других единицах не складываются друг с другом. Для неизвестной единицы итог количества не рассчитывается.

В примечаниях к заголовкам Excel указывается источник данных. Историческая выручка не считается по текущей цене: для суммы продаж используйте отдельную выгрузку с фактическими суммами.

## Другие ведомости и справочники

- При наличии пяти однозначно распознанных полей (товар, количество продаж, сумма продаж, количество и сумма конечного остатка) также открывается сразу готовый отчёт. Форматы: `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.tsv`. Только если заголовки не определены, программа предлагает указать столбцы вручную, без предпросмотра исходной таблицы. Для файла без заголовка укажите `0` и `0`. Формулы Excel предварительно пересчитайте и сохраните: читаются сохранённые значения.
- CSV поддерживает разделители `;`, запятую и табуляцию, кодировки UTF-8, Windows-1251 и UTF-16 с BOM. Десятичная запятая и точка поддерживаются. Пустое значение и прочерк остаются пустыми, числовой `0` сохраняется. Итоги и повторные заголовки пропускаются. Детальные строки не суммируются.
- Автогруппировка использует **только название товара**. Столбец «Группа номенклатуры» не нужен и не влияет на результат. В **Справочник групп… → Правила распознавания** заполнены фразы для всех назначаемых групп, включая №100. Условия «В начале», «Исключить» и дополнительные фразы задаются отдельными полями, без технических знаков. Есть поиск по списку. Добавление, замена и удаление фраз влияют на новые и текущие автоназначения, но не на сделанные вручную. Совпадение разных групп или отсутствие совпадения оставляет ячейку пустой. См. [редактор правил и проверку пункта №53](docs/recognition.md).
- **Справочник групп…** показывает полный текст всех пунктов. Другую версию можно загрузить из PDF с текстовым слоем и проверить перед сохранением. Для скана нужен OCR или ручной ввод. Кнопка **Встроенный справочник** восстанавливает исходный текст 4-торг. Локальная копия хранится в `%LOCALAPPDATA%\Statistika\catalog.json`.

## Сборка и развитие

GitHub Actions запускается на каждый `push`: тесты → сборка Windows x64 → проверка запуска EXE → артефакт `Statistika-Windows-x64`. Публикация в Releases включается явным релизным коммитом; см. [AGENTS.md](AGENTS.md).

Локальная разработка на Windows: Python 3.12 с Tcl/Tk. В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m statistika
```

Сборка `dist\Statistika.exe` на Windows:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --name Statistika --paths . --add-data "statistika/data/catalog.json:statistika/data" statistika/__main__.py
```
