# Статистика — продажи и остатки

Локальная программа для Windows x64: загружает товарную ведомость, предлагает товарные группы и сохраняет результат в Excel. Исходные файлы не изменяются и не отправляются по сети.

**Состояние исходников.** В исходном коммите репозитория `f20f907` был только `README.md`: PDF и ведомость не найдены. Поэтому в сборку не включены догадки об описаниях пунктов. Встроена только группа **№100 — Чулочно-носочные изделия**. Остальные описания заполняются из вашего PDF в самой программе. На реальном PDF и реальной ведомости формат пока не проверен.

## Как получить `Statistika.exe`

На GitHub откройте **Actions → Сборка Statistika для Windows** и выберите успешный запуск нужной ветки. В его разделе **Artifacts** скачайте `Statistika-Windows-x64`, распакуйте ZIP и откройте `Statistika.exe`. Устанавливать Python для запуска EXE не нужно. Артефакты хранятся 30 дней; сборка не подписана цифровой подписью.

GitHub Actions запускается при каждом `push` независимо от ветки, выполняет тесты, собирает EXE и проверяет, что собранная программа запускается. Локальное сохранение файлов без `push` сборку на GitHub не запускает.

## Как пользоваться

1. Откройте **Справочник групп… → Загрузить PDF…**. Сверьте извлечённый текст с исходником, при необходимости поправьте строки `35. Описание` и нажмите **Сохранить справочник**. Программа хранит все подтверждённые пункты, а для назначения даёт только №35–43, 45, 46, 53, 57, 63 и 100. Если какой-то пункт отсутствует, он показан как «описание не загружено». Для скана без текстового слоя нужно предварительное OCR либо ручной ввод точного текста. В хранилище остаются текст пунктов и правила, не сам PDF.
2. Нажмите **Открыть ведомость…**, выберите книгу и лист. Проверьте предложенные номера первой и последней строк заголовка и пять исходных столбцов. Если строки заголовка изменились, нажмите **Обновить**; для файла без заголовка укажите `0` и `0`. Неоднозначные столбцы нужно выбрать руками. «Расход» выбирайте только если в конкретной ведомости он действительно означает продажи. Нажмите **Построить таблицу**.
3. Щёлкните первый столбец нужной строки (или выберите строку и нажмите `Enter`), чтобы назначить другую группу либо оставить ячейку пустой. Фильтр **Только без группы** помогает пройти строки без совпадения. На вкладке **Правила распознавания** можно добавить проверенные фразы — по одной в строке. Сохранение справочника пересчитывает только автоматические назначения, не затрагивая ручные.
4. **Сохранить Excel…** записывает все строки, в том числе нераспределённые и скрытые фильтром. Ручные назначения действуют в открытой таблице; для сохранения результата выгрузите Excel до закрытия или загрузки другой ведомости.

Порядок столбцов в окне и экспорте:

| № | Столбец |
|---|---|
| 1 | № пункта и описание из PDF, либо №100 и его описание. Без группы — пусто |
| 2 | Наименование товара |
| 3 | Количество, проданное за период |
| 4 | Сумма продаж за период |
| 5 | Количество в остатке на конец периода |
| 6 | Сумма остатка на конец периода |

## Какие данные поддерживаются

- **Ведомость:** `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.tsv`. Для вывода 1С в другом формате экспортируйте детальные товарные строки в Excel. Даты, продажи, начальные и конечные остатки приложение не рассчитывает: они должны уже относиться к нужному периоду в ведомости. Для формул Excel предварительно пересчитайте и сохраните книгу; читаются сохранённые значения, макросы не запускаются.
- **CSV:** UTF-8 (с BOM или без), Windows-1251 или UTF-16 с BOM. Разделитель `;`, запятая или табуляция. Числа с запятой в CSV с разделителем `,` должны быть в кавычках. Десятичная запятая и точка поддерживаются; единственная запятая или точка в числе считается десятичной. Разряды можно отделять пробелами. Пустота и прочерк в числе дают пустую ячейку, а число `0` остаётся нулём.
- **Импорт:** сохраняется порядок строк, одинаковые наименования не суммируются. Исключаются распознанные итоги (`Итого`, `Всего`), повторы заголовка и строки с наименованием, но без всех четырёх показателей. Если есть число без имени или недопустимое значение, импорт не создаёт частичный результат. Используйте детальную ведомость без немаркированных промежуточных итогов.
- **Автогруппировка:** ищет слова и последовательные фразы из простых описаний и добавленных правил, без учёта регистра и с нормализацией распространённых русских окончаний. Если совпадений нет или совпало несколько групп, первая ячейка остаётся пустой. Сложные описания с оговорками или скобками не используются как автоматические правила — задайте характерные фразы или назначьте группу вручную. Синонимы и сокращения в вашей номенклатуре нужно проверять по реальным примерам.

На Windows справочник сохраняется в `%LOCALAPPDATA%\Statistika\catalog.json` и открывается при следующем запуске.

## Локальная разработка

Python 3.12 с Tkinter (в Windows-установщике Python должен быть включён Tcl/Tk). В PowerShell из корня репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m statistika
```

Чтобы собрать Windows EXE на Windows:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --name Statistika --paths . --add-data "statistika/data/catalog.json:statistika/data" statistika/__main__.py
```

Откройте `dist\Statistika.exe`. Устройство проекта, тесты и план проверки на исходных файлах описаны в [AGENTS.md](AGENTS.md).
