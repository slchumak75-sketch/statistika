# Как работают правила распознавания

В **Справочник групп → Правила распознавания** есть исходный список для каждой назначаемой группы: №35–43, 45, 46, 53, 57, 63 и 100. Текст пунктов PDF хранится отдельно. Для автоназначения используются **только наименование товара и фразы справочника**, не склад и не «Группа номенклатуры» (`B`). При импорте программа не обращается к интернету. Ссылки ниже — основания для исходного набора фраз и для дальнейших ручных проверок.

## Редактирование

Выберите группу, впишите по одной фразе на строку и нажмите **Сохранить справочник**. Автоматические назначения в уже открытой таблице пересчитаются; ручные, включая очистку, останутся. Сохранённые фразы применяются к последующим ведомостям. Регистр, `ё`/`е`, окончания и обычная пунктуация нормализуются. Слова фразы должны идти подряд, если не указан ` + `.

| Строка в редакторе | Действие |
|---|---|
| `белмастер экобио` | Фраза в любом месте наименования; объём для совпадения не нужен |
| `^антисептик` | Совпадение только в начале наименования (допускается короткий числовой префикс ведомости) |
| `^муфта + бифип` | «Муфта» в начале, «БИФИП» где угодно дальше в названии |
| `!для рук` | Исключение только для выбранной группы, даже если сработала положительная фраза |
| `# Подтверждено карточкой товара` | Комментарий, не участвует в распознавании |

Если после исключений не осталось кандидатов или разные группы совпали одновременно, ячейка пустая. В каждой группе можно удалить одну фразу или очистить весь список. Удаление всех положительных фраз отключает автоназначение, включая №100; скрытых правил нет. **Исходные фразы** восстанавливают список выбранной группы после подтверждения. Для другого PDF, с изменёнными описаниями, исходные правила не переносятся автоматически; проверьте прежние вручную сохранённые списки перед применением.

## Как проверяли пункт №53

Пункт №53 **инструкции** относится к строке **51 формы**. Граница для отчёта — код **47.52** в [1](https://www.belstat.gov.by/upload-belstat/upload-belstat-pdf/klassifikatory/SC_33_004_2020-260114.pdf), а не бытовое название отдела магазина. У Белстата указаны группы, не перечень марок или артикулов. Поэтому коды помогают определить границу, а конкретные фразы выбираются по назначению товара.

- **47.52.11, §78:** замки и фурнитура, крепёж, ручной инструмент и рабочая оснастка (например, свёрла, диски, малярный инструмент). Моторизованный ручной инструмент в этой подгруппе — до 10 кг; для тяжёлого или неясного оборудования нужна отдельная проверка. [1](https://www.belstat.gov.by/upload-belstat/upload-belstat-pdf/klassifikatory/SC_33_004_2020-260114.pdf)
- **47.52.12, §79:** ЛКМ, грунты и составы подготовки поверхностей, защитные покрытия и антисептики для древесины. **47.52.13–14, §§80–81:** листовое стекло и материалы/оборудование с назначением для домашних поделок. [1](https://www.belstat.gov.by/upload-belstat/upload-belstat-pdf/klassifikatory/SC_33_004_2020-260114.pdf)
- **47.52.15, §82:** сантехника и её комплектующие: например, смесители, душевые лейки, фитинги, трубы для воды и канализации. **47.52.16, §§83–91:** пиломатериалы и плиты, цемент, кирпич, черепица, плитка, смеси, проёмы, отделка, изоляция и кровля. [1](https://www.belstat.gov.by/upload-belstat/upload-belstat-pdf/klassifikatory/SC_33_004_2020-260114.pdf)
- Обычные обои, ламинат, линолеум и ковры — **47.53**; жидкие обои и монтажные пороги — **47.52.16.900**. Кабели и электроустановочные товары — **47.59.12.200**, лампы — **47.59.12.100**. Использование на ремонте само по себе не переносит их в строку 51. Кожные антисептики прямо указаны в пункте №62 исходной инструкции, вне выбранных групп. [1](https://www.belstat.gov.by/upload-belstat/upload-belstat-pdf/klassifikatory/SC_33_004_2020-260114.pdf)
